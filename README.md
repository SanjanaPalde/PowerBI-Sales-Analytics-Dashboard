# 📊 Power BI Sales Analytics Dashboard

An interactive **Sales Analytics Dashboard built with Microsoft Power BI** to analyze sales performance across different categories, markets, countries, states, cities, and shipping modes.

The dashboard provides a visual overview of important business metrics such as **Total Sales, Total Profit, and Total Shipping Cost**, helping users understand sales performance and identify key markets and locations.

---

## 📌 Project Overview

This project demonstrates how **Power BI** can be used to transform sales data into an interactive and easy-to-understand business intelligence dashboard.

The dashboard focuses on:

* Sales performance analysis
* Profit analysis
* Shipping cost analysis
* Category-wise sales
* Market-wise sales
* Country-wise sales
* State-wise performance
* City-level analysis
* Shipping mode analysis
* Interactive filtering

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze overall sales performance.
* Identify high-performing countries and states.
* Compare sales across different markets.
* Analyze sales based on shipping modes.
* Understand category-level performance.
* Track important KPIs such as sales, profit, and shipping costs.
* Create an interactive dashboard for business decision-making.

## 📊 Dashboard Features

### 💰 Key Performance Indicators

The dashboard displays important KPIs including:

* **Total Sales**
* **Total Profit**
* **Total Shipping Cost**

### 📦 Category Analysis

Analyze sales performance across different product categories.

### 🌍 Market Analysis

Compare sales across different markets to identify the strongest-performing regions.

### 🚚 Ship Mode Analysis

Analyze sales based on different shipping methods.

### 🗺️ Geographic Analysis

The dashboard provides geographic analysis using:

* Country
* State
* City

This helps identify high-performing locations.

### 🏆 Top Performing Locations

The dashboard highlights:

* Top countries by sales
* Top states by sales

### 🎛️ Interactive Filtering

Users can interact with the dashboard using slicers, including the **Category** filter.
